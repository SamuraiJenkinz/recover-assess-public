# Phase 261116-915 Plan 01: Scrub client-specific nomenclature Summary

A stdlib-only, hash-based blocked-term scanner now runs as a seventh step of the single quality gate, and every tracked file has been rewritten in neutral language so the scanner reports zero hits.

## What was built

- **Task 1 (tracer), commit 68d6ac5:** `scripts/blocked_terms.py` scans each file from `git ls-files` against five SHA-256 token digests. Tokens are `[A-Za-z0-9]+` runs plus camelCase and digit segments, matched whole-token only. Output lines are `path:line: blocked term` followed by a count, never the line content. A non-git directory or git failure returns exit 2. `--hash-term WORD` prints the digest for adding a new term. `scripts/check.py` gained the `blocked-terms` step between `import-contracts` and `pytest`; `tests/unit/test_check_script.py` was updated to seven steps; the README quick-check bullet mentions the new check. Tests inject the digest of a harmless word, so no test spells a blocked term. At the end of this task the checker found the 100 known lines in 13 files, all under `.claude/` and `.planning/`, proving end-to-end detection.
- **Task 2, commit 4340bc4:** the five research documents and `.claude/CLAUDE.md` were scrubbed (75 lines). The organisation became "the pilot organisation", the gateway names became "the corporate LLM gateway" or "the corporate Anthropic proxy (Apigee-fronted)", and the two local skill names became "the user's local gateway-troubleshooting / Anthropic-proxy skill (not in repo)". URL path shapes, header names, model IDs, error codes and quirks are unchanged (7 `coreapi/` references kept, no redaction markers, no doubled words).
- **Task 3, commit af6f009:** PROJECT, REQUIREMENTS, ROADMAP and the Phase 1 CONTEXT, RESEARCH and VERIFICATION documents were scrubbed (the STATE.md edit is in the working tree, see below). The W-A paragraph in the verification report records its resolution by this task. `test_the_repository_has_no_blocked_terms` runs `scan_repo` over the real repository inside pytest.
