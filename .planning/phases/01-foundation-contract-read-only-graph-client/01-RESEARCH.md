### Locked Decisions

The user approved sign-off 1 and accepted Claude's recommendations for the four remaining gray areas without further discussion. The recommendations are recorded here as locked decisions.

**Sign-off 1: HTTP stack (resolved)**
- **D-01:** Use `httpx2` (~=2.16) for all outbound HTTP, and the built-in `httpx2.MockTransport` for tests, through one client factory that accepts `transport=`. `httpx` and `respx` are not dependencies. Swapping the stack touches graph.py, the client factory and every Graph test.

**CI and task runner**
- **D-02:** CI runs on GitHub Actions in `.github/workflows/ci.yml` with a matrix of `windows-latest` (primary, required) and `ubuntu-latest`, Python 3.12, `uv sync --locked`. Steps: ruff check, ruff format --check, mypy strict, `lint-imports`, pytest (includes the schema-drift and repo-scan tests). No live network in CI. There is no git remote yet. - **D-03:** No Makefile, because `make` is not on a stock Windows 11 machine. - **D-04:** The deliberate-violation check (success criterion 1) is a test fixture: a set of throwaway modules that break each import contract, checked by running import-linter against them. Contracts must not be weakened to make them pass.

**Fact-sheet v1.0 shape**
- **D-05:** Model the **full** provisional v1.0 fact sheet now: envelope, `input`, `site`, `libraries[]`, `lists[]`, `exposure_total`, `ownership`, `sample_candidates`, `sam`, `graph_stats`, `warnings`, plus the FND-05 fields (`privacy`, `collect_limits`, per-section `status`/`reason`, `coverage`, `truncated_reason`, `path_unresolved`, `hash_coverage`, `owners_source`, `last_activity` basis). **Allow-list ownership**
- **D-08:** The Graph allow-list is **packaged and locked**, not operator-editable. Templates live inside the package (for example `src/recover_assess/core/graph_allowlist.yaml` loaded with `importlib.resources`, or a Python constant; the planner chooses) and not in the user-facing `config/` directory. ## Summary

Phase 1 is mostly standard patterns, and the existing research already settles the design. The value added here is that several details the plan would otherwise discover at execution time were reproduced and have non-obvious answers. The five that change the plan: (1) tenacity's `stop_after_delay` and `wait_exponential_jitter` use the real clock and global `random`, so the 5-minute give-up and jitter must be custom callables on the injected `Clock` or the GRPH-05 tests silently run 50 attempts; (2) passing `transport=` to `httpx2.AsyncClient` disables environment proxies (`allow_env_proxies = trust_env and transport is None`), so the production client must not be given a wrapping transport and the read-only guard must be an `event_hooks["request"]` hook, which also runs before `MockTransport` so tests exercise the same guard; (3) import-linter errors when a contract names a module that does not exist or when an `ignore_imports` entry matches nothing, so Phase 1 must create empty stub packages (`score`, `agent`, `report`, `providers`, `collect`, `run`) and set `unmatched_ignore_imports_alerting = "none"`; (4) `uv_build` includes package data (`graph_allowlist.yaml`) in wheel and sdist by default and does not ship `.planning/` or the root drafts, but root dirs (`schemas/`, `config/`, `scripts/`, `tests/`) need explicit `source-include`, and spaces in glob patterns are a build error; (5) `pydantic-settings` with `extra="forbid"` rejects nested env typos but silently ignores a mistyped top-level group (`RECOVER_ASSESS__COLECT__...`), so the env-typo scan is mandatory, not optional.

This developer machine has no `uv` and no Python 3.12 (3.13.3 and 3.10 only). `uv python install 3.12` and `uv sync --locked` both worked without admin in my scratch run, so Wave 0 must install uv first (user-level). All 17 recommended packages were flagged `SUS` by the legitimacy seam only because it returned `null` download counts and "too-new" latest-release dates; pypistats shows tens of millions of weekly downloads. A single consolidated human-verify checkpoint at lockfile creation is the proportionate response.

**Primary recommendation:** Build tracer-first. Plan 01 delivers the scaffold plus the single local/CI gate with the deliberate-violation test (FND-01/02). Plan 02 is the walking skeleton: one allow-listed `GET` through `graph.py` on `MockTransport`, writing one typed JSONL request line, with the read-only guard already in place. Contract, config/atomic-write/repo-scan run in parallel with it. Then harden the policy and paging, then throttle/batch/concurrency, then an acceptance test that exercises success criteria 3 and 4 together.

### Pattern 1: ReadOnlyPolicy (pure) + two independent guards
**What:** `ReadOnlyPolicy.check(method, url, *, batch=None)` is called by `_send` before anything else; an `httpx2` request event hook repeats a coarse check (method in {GET, POST}; POST only to `/v1.0/$batch`; host `graph.microsoft.com`) as defence in depth.
**Why a hook, not a transport wrapper:** `allow_env_proxies = trust_env and transport is None` (httpx2 `_client.py:1495`) `[VERIFIED: scratch-venv, source inspection]`. A wrapping transport would silently disable `HTTPS_PROXY`/`NO_PROXY` in production, which is a TLS/proxy regression the unit tests (on MockTransport) would never see. The hook runs before the transport: a hook raising on `DELETE` left the MockTransport handler uncalled (1 call for the allowed GET only) `[VERIFIED: scratch-venv]`.
**Rules:** canonicalise before matching (reject control chars and `\`, any `..`/`.`/empty segment, `%2f` `%5c` `%00`, fragments); absolute URLs require scheme `https`, `netloc == "graph.microsoft.com"` exactly (this rejects userinfo `host@evil`, ports, trailing-dot host, upper-case host), path prefix `/v1.0/`; `$batch` sub-request `url` must be relative and must NOT repeat `/v1.0` (the Learn page shows `"url": "/me/memberOf"` and a no-leading-slash form `users?$select=...`, so normalise a missing leading `/`) `[CITED: learn.microsoft.com/en-us/graph/json-batching]`; allowed query keys are a global set; any `$select`/`$expand` value containing `downloadUrl` is rejected. `base_url` + an absolute URL uses the absolute URL verbatim (`https://evil.example/x` was fetched as-is), so validation must precede every `client.get(next_link)` `[VERIFIED: scratch-venv]`.
**Result:** `GraphPolicyError` base; `WriteAttemptError(GraphPolicyError)` for verb/body/`dependsOn`; `UrlNotAllowedError(GraphPolicyError)` for host/prefix/template/query/redirect. Public client surface exposes no `post/put/patch/delete`.

### Pattern 2: GraphClient, GraphSession, gate, breaker, concurrency, stats
- **Spec numbers (fixed):** quoted below under Code Examples.
- `GraphClient.open_session(site_key)` is an async context manager that first acquires `Semaphore(max_sites=2)` (GRPH-06 "2 sites at a time" enforced at the client, not by a future scheduler), then yields a `GraphSession` holding `Semaphore(4)`, a breaker (deque of throttle monotonic timestamps, sliding 60 s window, trips at 20), and `GraphStats`.
- **ThrottleGate** (client-level, shared): `resume_at` monotonic; `wait()` sleeps `resume_at - now` via `clock.sleep` until non-positive; `trip(delay)` does `resume_at = max(resume_at, now + delay)`. Because the retrying request's own tenacity sleep equals the delay it just tripped, its next `gate.wait()` finds ~0 remaining: no double sleep `[VERIFIED: scratch-venv prototype]`.
- **Failure type:** one `ThrottledOut(reason)` with `reason in {"retries_exhausted","budget","breaker"}`; a tripped breaker poisons the session so later calls raise immediately without sending (design choice, A7; collectors map it to warning code `throttled_out`).
- **Per-request budget:** if `elapsed + next_delay > 300 s`, raise `ThrottledOut("budget")` immediately instead of sleeping then failing (prototype: three 100 s sleeps then fail, not four).
- **`graph_stats` semantics (define now, tests pin them):** `requests` = every HTTP attempt actually sent (retries and each `$batch` POST count once each), `batches` = number of `$batch` POSTs, `throttled` = count of 429/503 responses plus throttled sub-responses, `retries` = re-attempts of single requests plus re-queued sub-requests, `seconds` = session wall time from `clock.monotonic()` (do NOT use `response.elapsed`: it raises `RuntimeError` under MockTransport `[VERIFIED: scratch-venv]`). Keys must equal the spec example `{"requests": 1840, "batches": 61, "throttled": 2, "retries": 3, "seconds": 412}`.
- **Token source:** `token: Callable[[], Awaitable[str]]` injected; attached per attempt; never stored on the stats/log objects.
- **UA header:** `User-Agent` built from config (`NONISV|<company>|recover-assess/<ver>` when a company is configured; PITFALLS #7); no client string defaults in the repo.

### Pattern 3: Paging and cap
`iter_pages(path, params)` is the primitive (async generator of `Page(items, next_link)`; each `next_link` goes through the same policy before the request). `get_all(path, params, *, cap)` collects until `len(items) >= cap` and a `nextLink` still exists, then returns `PagedResult(items, truncated=True, cap=cap)`; if the cap is reached exactly on the last page (no nextLink) `truncated` is False (explicit boundary test). Never construct `$skiptoken` by hand (spec line 127). Strip `@microsoft.graph.*` keys from every JSON object before returning (keeps `@odata.nextLink`, `@odata.deltaLink`, `@odata.count`).

### Pattern 4: `$batch`
`batch(items: list[BatchItem])` chunks to <=20, assigns numeric string ids (`"1".."20"`; ids are case-insensitive and must be unique or the whole batch is 400 `[CITED: json-batching]`), sends one POST per chunk, correlates responses by `id` (out-of-order is documented), returns per-item `BatchResult(status, body, error)` and never raises for a sub-4xx. Sub-429/503: re-queue only those ids after the longest sub `Retry-After` (also `gate.trip` it and count it toward the breaker); bounded by the same 6-retry / 300 s limits. A sub-response carrying `@odata.nextLink` is completed by `iter_pages` (follow-up paged GET), not re-batched. Sub-requests are built by our code as `{"id","method":"GET","url"}` only; the policy's raw-body validator additionally rejects `body`, `dependsOn`, non-GET (case-insensitive), absolute URLs, nested `$batch`. Spec line 129: "Small independent GETs ... go in `$batch` groups of 20 or fewer."

### Pattern 5: Typed JSONL log + scrub (GRPH-07)
`core/log.py`: `RunLog(path_or_stream, clock)` with `emit(event)` where `event` is a pydantic model from a closed union (`RequestEvent`, `RetryEvent`, `WarningEvent`; define `SiteStateEvent`, `CollectorStartEvent`, `CollectorEndEvent` now so Phase 2/3 only emit). `extra="forbid"` and no free-text body field means a body cannot be logged by construction. Defence in depth: a final scrub over the serialised line (Bearer tokens, JWT shape `eyJ...`, `sig=`, `tempauth`, `downloadUrl`, `api-key`) and exception messages reduced to class name + path template (httpx exception text includes URLs). One `request` line per HTTP attempt, with `retry` = attempt index (0 for the first), `status`, `duration_ms` (injected clock), `request_id` from the `request-id` header (fallback `client-request-id`), `template` from the matched allow-list template (IDs are `{id}` by construction), `site` = opaque site key supplied by the session (not a URL or title). `$batch`: one outer `request` line (`template="/$batch"`, `batch_size`) plus one `request` line per sub-response with `via_batch=true`. `run.jsonl` is an append-only stream (single writer, flush per line); FND-06 atomic replacement applies to artifacts, not this log (document the exception).

### Pattern 6: Fact-sheet contract and schema generation (FND-04/05)

### Pattern 8: Import-linter contracts and the deliberate-violation fixture (FND-02, D-04)
Verified config (4 contracts KEPT on the stub tree; each deliberate violation turned exactly the expected contracts BROKEN) `[VERIFIED: scratch-venv, import-linter 2.16]`. See Code Examples. Key facts:
- `include_external_packages = true` is required to name `httpx2`, `openai`, etc. Imports are squashed to the external root, so `from httpx2 import AsyncClient` is caught.

- **Violation fixture (`tests/support/import_violations.py` + `tests/unit/test_import_contracts.py`):** for each case copy the real `src/recover_assess` tree to `tmp_path`, write the violating module, run `lint-imports --config <the REAL pyproject.toml> --no-cache` in a subprocess with `PYTHONPATH=<tmp>/src` and `cwd=<tmp>`, and assert exit 1 and that the expected contract name is in the `BROKEN` lines. Import-linter cannot see `importlib.import_module("httpx2")`; cover with ruff `TID251` (below) and an AST test.

### Pattern 9: Atomic writer (FND-06)
Reproduced on this machine `[VERIFIED: scratch-venv]`: `os.replace(tmp, target)` while another handle has `target` open raises `PermissionError: [WinError 5] Access is denied`; replacing while the *tmp* is still open raises `[WinError 32]`; opening a directory for `fsync` raises `PermissionError` on Windows, so directory fsync cannot be done (do not pretend). Writer: temp file `.{name}.tmp-{pid}-{n}` in the same directory, write, `flush`, `os.fsync(fd)`, close, then `os.replace` in a bounded retry (about 10 tries, 50-250 ms jittered, sleep injected) on `PermissionError`; always unlink the tmp in `finally`; never fall back to a non-atomic copy; on persistent failure raise a clear `OutputError`. API: `atomic_write_bytes`, `atomic_write_text` (UTF-8, `newline="\n"` via bytes), `atomic_write_json`. Add `sweep_orphans(dir)` for `*.tmp-*`. Tests: (a) deterministic, platform-independent: inject `replace` that raises `PermissionError` N times; (b) injected failure between write and replace (patch `os.fsync` to raise) leaves target untouched/absent and no tmp; (c) Windows-only: hold the target open, assert retry exhausts with the clear error, release in a thread mid-retry and assert success (`pytest.mark.skipif(sys.platform != "win32")`).

### Anti-Patterns to Avoid
- **`tenacity.stop_after_delay` / `wait_exponential_jitter` / `wait_random_exponential`:** real clock and global `random`; untestable on the injected clock (Pitfall 1).
- **A wrapping `httpx2` transport in production:** disables env proxies (Pitfall 2).
- **`respx`, `httpx`, `pytest-httpx`, `vcrpy`:** not dependencies (D-01); cassettes risk committing tenant data.
- **Real `asyncio.sleep` / `time.sleep` in `src` or tests:** ban with ruff `TID251` so only `core/clock.py` can sleep.
- **Defaults on published models:** hides missing collector output; breaks "every key required".
- **Reading `response.elapsed`:** raises under MockTransport.
- **Logging `str(exc)` from httpx:** contains URLs.
- **Editable allow-list in config:** violates D-08.

## Don't Hand-Roll

| Problem | Don't Build | Use Instead | Why |
|---------|-------------|-------------|-----|
| JSON schema generation | A hand-written schema | `model_json_schema(mode="serialization")` with `json_schema_serialization_defaults_required=True` | Source of truth is the models (D-07) |
| Schema validation in tests | Custom validator | `jsonschema.Draft202012Validator` | Verified on the generated schema |
| Layered config | Custom precedence code | `pydantic-settings` `settings_customise_sources` | Deep-merge and env nesting verified |
| Architecture rules | Grep-based import checks | import-linter (+ ruff `TID251` for dynamic imports) | Handles indirect chains and external packages |
| HTTP mocking | A fake socket/server | `httpx2.MockTransport` with sync or async handler | Built in; async handler verified |
| Env typo detection | Regex over `os.environ` ad hoc | The model-path walker (Pattern 7) | Needs `model_fields` to avoid false positives |
| Retry loop state machine | Bare `while` loops scattered in collectors | One `AsyncRetrying` driver in `_send` | One place to test (custom callables only) |
| Date-form `Retry-After` | Manual date parsing | `email.utils.parsedate_to_datetime` | Verified on `Sun, 15 Nov 2026 00:00:30 GMT` |
| Percent-decoding / URL parsing | Regex over raw URLs | `urllib.parse.urlsplit` / `unquote` / `parse_qsl` | Hostile corpus passes (Pattern 1) |

**Key insight:** the novel code in this phase is small (policy canonicaliser, gate, retry callables, batch chunker, atomic writer, typed log). Everything else is configuration of well-known tools, so the plan's effort belongs in tests and in pinning behaviours.

## Common Pitfalls

### Pitfall 1: tenacity's time and jitter are not injectable
**What goes wrong:** `stop_after_delay(300)` uses `time.monotonic()` (set in `RetryCallState.__init__`), so with a fake clock the 5-minute give-up never fires. With a loop forcing 100 s waits and `stop_any(stop_after_attempt(50), stop_after_delay(300))`, the test ran **50 attempts / 4900 fake seconds** instead of 4 `[VERIFIED: scratch-venv]`. `wait_exponential_jitter` uses the global `random`.
**How to avoid:** custom `stop(rs)` comparing `clock.monotonic() - start`; custom `wait(rs)` using an injected `random.Random` for full jitter `uniform(0, min(60, 1 * 2**n))`; pass `sleep=clock.sleep`. The proven prototype is in Code Examples.
**Warning signs:** retry tests that take real seconds, or assert only "eventually succeeds".

### Pitfall 2: passing `transport=` disables env proxies
**What goes wrong:** `allow_env_proxies = trust_env and transport is None`. A prod client built with a custom/wrapped transport ignores `HTTPS_PROXY` and `NO_PROXY`; the unit tests cannot notice.
**How to avoid:** factory `make_http_client(cfg, *, transport=None, verify=None)` passes `transport` only when a test supplies it; guard via `event_hooks`. Add one test asserting that with `transport=None` and `HTTPS_PROXY` set the client has a proxy mount (`client._mounts` non-empty) and with a transport it does not, so a regression is visible.

### Pitfall 3: import-linter fails on missing modules and unmatched ignores
**What goes wrong:** Contracts referencing `recover_assess.core.score` etc. exit 1 until those packages exist; `ignore_imports = ["...providers.** -> httpx2"]` exits 1 ("No matches for ignored import") while no provider imports httpx2 yet `[VERIFIED: scratch-venv]`.

### Pitfall 4: relative sub-request URLs and `/v1.0` in `$batch`
**What goes wrong:** policy written for absolute URLs rejects `"url": "/sites/x"` or accepts `/v1.0/sites/x` inside a batch (Graph returns 4xx for the latter; Learn shows relative urls, one without a leading slash).
**How to avoid:** separate `absolute=False` mode: reject scheme/host and a leading `v1.0/`; normalise missing `/`.

### Pitfall 5: `uv_build` glob rules
**What goes wrong:** space in an exclude glob breaks `uv build`; include globs are anchored (`schemas/**`), excludes are not.
**How to avoid:** see Pattern 11; add the sdist content test to CI (needs `uv`, available there).

### Pitfall 6: top-level env typos pass silently
Covered in Pattern 7; the scan is mandatory and is called on every `load_settings`.

### Pitfall 7: schema drift false failures on Windows
`core.autocrlf=true` converts the checked-in JSON to CRLF; a text-equality drift test then fails on Windows only. Compare parsed JSON and set `.gitattributes`.

### Pitfall 8: unclosed `httpx2.AsyncClient` plus `filterwarnings=["error"]`
A `ResourceWarning` becomes a test failure. `GraphClient` must be an async context manager (`aclose()`), and `fake_graph`/`conftest` fixtures must close it.

### Pitfall 9: FakeClock semantics
My `FakeClock.sleep` is "advance-on-sleep": `t += d` then `await asyncio.sleep(0)`. It is not a discrete-event scheduler, so concurrent sleepers advance time additively. That is sufficient for the gate/breaker assertions (waiters compute `resume_at - monotonic()` and find it already elapsed) but do not assert exact interleaved wake order across tasks. Concurrency (4/2) tests use real task interleaving by yielding (`await asyncio.sleep(0)` only inside the **fake server**, which is under `tests/` and exempt from the `TID251` ban via per-file-ignores) while counting in-flight.

### Pitfall 10: canary and fixtures trip the repo scan
Canary tokens, fake `downloadUrl`s and fixture GUIDs/hosts live in `tests/`, which is scanned. Use `example.com`/`contoso`, synthetic GUIDs, runtime-constructed tokens.

Ruff 0.16+ enables 413 rules by default even alongside `select`; set `select` explicitly and `extend-select` nothing. Per-file ignores needed: tests `S101`, `S105/S106` (fake tokens), `PLR2004`; `cli.py` and `scripts/` `T20`; `core/clock.py` `TID251`; `tests/fakes/` `TID251` and `ASYNC`.

### Policy canonicaliser (prototype; ran against 4 valid and 23 hostile URLs: 4 accepted, 23 rejected)
```python
# [VERIFIED: scratch-venv prototype]  core/graph_policy.py (no httpx2 import)
HOST = "graph.microsoft.com"
ID = re.compile(r"^[A-Za-z0-9!_.,=~-]+$")                      # A2: confirm against live IDs in Phase 2
ALLOWED_QUERY = {"$select", "$expand", "$top", "$filter", "$skiptoken", "token"}

def canon(url: str, *, absolute: bool) -> str:                    # returns the matched template id
    if any(ord(c) <= 0x20 or ord(c) == 0x7F for c in url) or "\\" in url: raise UrlNotAllowedError("control/backslash")
    p = urlsplit(url)
    if absolute:
        if p.scheme != "https" or p.netloc != HOST or not p.path.startswith("/v1.0/"): raise UrlNotAllowedError(...)
        path = p.path[len("/v1.0"):]
    else:                                                          # $batch sub-request
        if p.scheme or p.netloc: raise UrlNotAllowedError(...)
        path = p.path if p.path.startswith("/") else "/" + p.path
    if p.fragment or "%2f" in path.lower() or "%5c" in path.lower() or "%00" in path.lower(): raise UrlNotAllowedError(...)
    segs = [unquote(s) for s in path.split("/")[1:]]
    if any(s in ("", ".", "..") or "/" in s or "\\" in s for s in segs): raise UrlNotAllowedError(...)
    for k, v in parse_qsl(p.query, keep_blank_values=True):
        if k not in ALLOWED_QUERY or "downloadurl" in v.lower(): raise UrlNotAllowedError(...)
    return match_template(segs)          # literal segs compared case-sensitively; {id} = ID.fullmatch; unmatched -> UrlNotAllowedError
```

### Retry driver on an injected clock (ran: 200 after sleeps [5.0, 1.689, 30.0]; exhaustion = 7 calls and 6 sleeps; budget = 3x100 s then fail fast)
```python
# [VERIFIED: scratch-venv prototype]  inside GraphClient._send (condensed)
start = clock.monotonic()
def delay_for(rs):                                   # tenacity `wait`: custom, clock/rng injected
    exc = rs.outcome.exception()
    ra = exc.retry_after if isinstance(exc, Throttled) else None
    d = ra if ra is not None else rng.uniform(0, min(60.0, 1.0 * 2 ** (rs.attempt_number - 1)))   # full jitter
    if clock.monotonic() - start + d > 300.0: raise ThrottledOut("budget")                      # fail fast
    gate.trip(d); stats.throttled += 1; breaker.record(clock.monotonic())                       # breaker may raise ThrottledOut("breaker")
    return d
def stop(rs): return rs.attempt_number > 6           # 1 initial + 6 retries
async for attempt in AsyncRetrying(sleep=clock.sleep, wait=delay_for, stop=stop,
                                   retry=retry_if_exception_type(Throttled), reraise=True):
    with attempt:
        await gate.wait(); policy.check(...); r = await http.request("GET", url, headers=...)   # 429/503 -> raise Throttled(parse_retry_after(...))
```
`parse_retry_after(value, clock)`: `float(value)` else `email.utils.parsedate_to_datetime(value) - clock.utcnow()`, clamped at 0, `None` if unparseable. Only 429/503 are retried; other 4xx (and other statuses) are returned/raised once with no retry, per spec.

### Known Threat Patterns
| Pattern | STRIDE | Standard Mitigation |
|---------|--------|---------------------|
| Bearer token sent to attacker host via poisoned `@odata.nextLink` or redirect | Information disclosure | Validate scheme/host/prefix/template before every follow; `follow_redirects=False`, manual validated hops |
| Allow-list bypass (`..`, `//`, `%2F`, case, userinfo, port, `/content`) | Elevation of privilege | Canonicalise first; anchored per-segment templates; hostile corpus + hypothesis |
| Write verb through a code bug | Tampering | Policy + request hook; no public write API; AST/ruff bans |
| Secrets in logs/tracebacks | Information disclosure | Typed events, scrub, `pretty_exceptions_show_locals=False`, canary test |
| `downloadUrl` (pre-authenticated URL) persisted | Information disclosure | Reject `downloadUrl` in `$select`; strip `@microsoft.graph.*` at the response boundary |
| Client data committed | Information disclosure | Repo scan + explicit sdist includes + gitignore |
| Supply-chain (new `httpx2`) | Tampering | Pin minor, lockfile, review checkpoint; documented fallback in STACK.md |
| Unsafe YAML | Tampering | `yaml.safe_load` only |
