## Phase Goal (user story)

**As a** developer, **I want to** run one command that proves the only path to Microsoft 365 is a tested read-only Graph client and that the fact-sheet v1.0 contract is generated from code, **so that** later collectors can be built safely on top of it.

This plan is the phase's Wave 0. It precedes the tracer (Plan 01-02, Task 1) because the package-legitimacy gate must clear before any third-party package is installed into an environment; it writes no Graph or contract code. Everything it creates is the scaffold the walking skeleton runs on.

## Scope justification (file count)

`files_modified` lists 28 paths, which is over the 15-file scope-sanity threshold. This was reviewed and kept deliberately, not split:

| Group | Count | Files | Context cost |
|-------|-------|-------|--------------|
| Docstring-only placeholders | 15 | 14 package markers: `src/recover_assess/core/__init__.py`, `core/{models,collect,score,agent,report,providers,run}/__init__.py`, `tests/__init__.py`, `tests/{unit,graph,integration,fakes,support}/__init__.py`. Plus the `core/graph.py` stub (docstring only; Plan 01-02 implements it) | One line each |
| Generated, not hand-written | 1 | `uv.lock` (written by `uv lock`, reviewed at the Task 2 checkpoint) | None to write |
| Substantive, Task 1 | 6 | `scripts/verify_sha256.py`, `pyproject.toml`, `.python-version`, `.gitignore`, `.gitattributes`, `README.md` | Normal |
| Substantive, Task 3 | 6 | `src/recover_assess/__init__.py`, `cli.py`, `core/errors.py`, `core/clock.py`, `config/README.md`, `tests/unit/test_foundation.py` | Normal |

Why the placeholders stay in this plan:
- import-linter exits 1 when a contract names a module that does not exist (RESEARCH Pitfall 3). So `core.graph` and the six stage packages must exist before Plan 01-03's contracts run in Wave 2.
- Creating every marker here means Plans 01-02, 01-03, 01-04 and 01-11 (Wave 2) never edit the same `__init__.py`, so they can run in parallel.
- A separate markers-only plan would add a wave before the tracer, and every downstream plan would need to wait for it. It would not lower the context cost, because together the 15 placeholders are under 20 lines.

The 12 substantive files are spread over 3 tasks, which is within the per-plan budget.
