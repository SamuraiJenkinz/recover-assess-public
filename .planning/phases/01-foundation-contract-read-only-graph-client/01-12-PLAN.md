src/recover_assess/core/output.py: atomic_write_bytes(path: Path, data: bytes, *, replace=None, sleep=None, attempts=10, rng=None) -> None. If path.parent does not exist raise OutputError("parent_missing"-style message naming only the file name). Temp path = path.parent / ("." + path.name + ".tmp-" + str(os.getpid()) + "-" + str(next(counter))) where the counter is a module-level itertools.count guarded by a threading.Lock. Open the temp with mode "xb" (exclusive create), write, flush, os.fsync(fileno), close; then call replace(tmp, path) (default: Path.replace) in a loop: on PermissionError sleep rng.uniform(0.05, 0.25) via the injected sleep (default SYSTEM_CLOCK.sleep_sync; core/output.py must not call time.sleep, which ruff TID251 bans) and retry, up to attempts; after the last failure raise OutputError. A finally block always unlinks the temp with missing_ok=True. Never fall back to a non-atomic copy. Directory fsync is not attempted (impossible on Windows; documented in the docstring, which also notes that run.jsonl, an append stream, gets its FND-06 safety from repair-on-open in core/log.py, Plan 01-02, per D-14, the 2026-11-15 FND-06 amendment, and that every other output file must go through this writer). atomic_write_text(path, text, **kw) encodes UTF-8 and delegates; atomic_write_json(path, obj, **kw) delegates with the json.dumps form above. sweep_orphans(directory: Path) -> list[Path] removes files in that directory (non-recursive) whose names match the temp pattern and returns them.

tests/unit/test_atomic_write.py covers every behavior above, injecting replace, sleep and rng for the deterministic cases and using pytest.mark.skipif(sys.platform != "win32") for the held-handle case.
